## 💻 OPZIONE 2: Installazione Locale

Se preferisci usare l'app solo su questo computer:

### PASSO 1: Installa Python (se non ce l'hai)

1. Vai su: **https://www.python.org/downloads/**
2. Scarica **Python 3.10 o superiore**
3. Durante l'installazione:
   - ✅ **IMPORTANTE**: Seleziona "Add Python to PATH"
   - Clicca "Install Now"

### PASSO 2: Avvia l'App

#### Windows
Doppio click su: **`START.bat`**

### Mac/Linux
1. Apri il Terminale
2. Digita: `bash START.sh`

L'app si aprirà automaticamente nel browser!

## ❓ Problemi?

### L'app non si avvia?

**Errore: "Python non trovato"**
→ Installa Python e assicurati di selezionare "Add to PATH"

**Errore: "streamlit non trovato"**
→ Apri terminale e digita: `pip install -r requirements.txt`

### Il CSV non viene caricato?

→ Usa il file `esempio_template.csv` per capire il formato corretto
→ Il CSV deve avere: Data, Descrizione, Importo

→ Leggi il [README.md](README.md) completo

## 🎓 Tutorial Rapido

### 1. Ottieni i dati dalla banca

**Intesa Sanpaolo:**
Area Clienti → Movimenti → Esporta CSV

**UniCredit:**
Banca via Internet → Movimenti → Scarica

**Poste Italiane:**
BancoPosta Online → Movimenti → Esporta

**Altre banche:**
Cerca "Esporta movimenti" o "Scarica CSV"

### 2. Carica nell'app

1. Clicca **📤 Carica Dati**
2. Trascina il file CSV
3. Verifica anteprima
4. Clicca **Salva**

### 3. Configura categorie e budget

1. Vai su **🏷️ Gestisci Categorie**
2. Imposta budget mensili (es. Alimentari: €500)
3. Ricategorizza transazioni se necessario

### 4. Monitora le spese

1. Torna su **🏠 Dashboard**
2. Visualizza grafici e statistiche
3. Ricevi alert se superi il budget
4. Usa **🔮 Previsioni** per pianificare
