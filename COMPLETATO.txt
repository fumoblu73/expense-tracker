================================================================================
  PROSSIMI PASSI
================================================================================

1. INSTALLA PYTHON (se non ce l'hai)
   → https://www.python.org/downloads/
   → Versione 3.10 o superiore
   → Durante installazione: seleziona "Add Python to PATH"

2. AVVIA L'APP
   Windows: Doppio click su START.bat
   Mac/Linux: bash START.sh

3. CARICA I DATI
   → Scarica CSV dalla tua banca
   → Vai su "📤 Carica Dati"
   → Trascina il file CSV
   → Salva nel database

4. CONFIGURA
   → Vai su "🏷️ Gestisci Categorie"
   → Imposta budget mensili
   → Ricategorizza transazioni

5. MONITORA
   → Dashboard per grafici e statistiche
   → Alert automatici sui budget
   → Report e analisi dettagliate

================================================================================
  CONFIGURAZIONE EMAIL (OPZIONALE)
================================================================================

Per ricevere report via email:

1. Ottieni password app Gmail:
   → https://myaccount.google.com/
   → Sicurezza → Verifica in due passaggi
   → Password per le app → Genera

2. Crea file: .streamlit/secrets.toml

3. Aggiungi:
   [email]
   sender = "tua-email@gmail.com"
   password = "password-app-generata"

4. Testa in: Impostazioni → Email
